# Сторонние компоненты

Prosvet — оболочка. Сам обход выполняют эти проекты, их авторам — огромное спасибо.

| Компонент | Что делает | Лицензия |
|---|---|---|
| [zapret2](https://github.com/bol-van/zapret2) (bol-van) | движок winws2 и Lua-стратегии | MIT |
| [zapret](https://github.com/bol-van/zapret) (bol-van) | движок winws | MIT |
| [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (Flowseal) | стратегии, фейки, списки доменов | MIT |
| [WinDivert](https://github.com/basil00/WinDivert) (basil00) | драйвер перехвата пакетов | LGPL-3.0 / GPL-2.0 |
| [Cygwin](https://cygwin.com) | `cygwin1.dll`, среда выполнения winws | LGPL-3.0 |
| [Unbounded](https://github.com/googlefonts/unbounded), [Manrope](https://github.com/davelab6/manrope) | шрифты интерфейса | SIL OFL 1.1 (`ui/fonts`) |
| [Simple Icons](https://simpleicons.org) | логотипы сервисов | CC0 |
| [Tauri](https://tauri.app) | оконная оболочка | MIT / Apache-2.0 |

Бинарники движков в репозиторий не входят — их скачивает `scripts/fetch-engine.ps1`
из официальных релизов, а установщик кладёт их рядом с приложением.
